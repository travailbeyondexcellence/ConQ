## 🏗️ Architecture Overview

### Communication Patterns

**1. Frontend ↔ Backend (GraphQL)**
```
Web/Mobile Apps → GraphQL (HTTP/HTTPS) → API Gateway (8080)
```

**2. Inter-Service Communication (gRPC - Synchronous)**
```
API Gateway → gRPC → Auth Service (50051)
API Gateway → gRPC → Content Service (50053)
Scheduler Service → gRPC → Publisher Service (50055)
```

**3. Event-Driven Communication (NATS - Asynchronous)**
```
Content Service → NATS: content.created → Other Services
Publisher Service → NATS: post.published → Analytics Service
Approval Service → NATS: approval.approved → Content Service
```

### NATS Event Subjects Defined

**Auth Events:**
- `auth.user.registered`
- `auth.user.login`
- `auth.user.logout`

**Content Events:**
- `content.post.created`
- `content.post.updated`
- `content.post.deleted`

**Scheduler Events:**
- `scheduler.post.scheduled`
- `scheduler.post.triggered`

**Publisher Events:**
- `publisher.post.completed`
- `publisher.post.failed`

**Approval Events:**
- `approval.requested`
- `approval.approved`
- `approval.rejected`

**Analytics Events:**
- `analytics.metric.recorded`
