## Color and Gradient Usage

### Background Effects
- Large gradient blobs positioned absolutely
- Primary, accent, and secondary colors at 10-20% opacity
- Blur effects (blur-3xl) for soft appearance
- Creates depth without overwhelming content

### Card Styling
- Border: `border border-border`
- Background: `bg-card`
- Text: `text-card-foreground`
- Shadow: `shadow-sm` to `shadow-2xl`
- Hover: `hover:shadow-xl hover:scale-105`

### Text Gradients
Used for emphasis on key phrases:
```
"All Platforms" → bg-gradient-to-r from-primary via-accent to-secondary
"Succeed" → bg-gradient-to-r from-primary to-accent
```

### Button Styles

**Primary CTA**:
- Background: `bg-gradient-to-r from-primary via-accent to-secondary`
- Text: `text-primary-foreground`
- Hover: Scale up + shadow increase

**Secondary CTA**:
- Border: `border-2 border-border`
- Background: `bg-card`
- Hover: Border becomes primary color

### Icon Badges
- Gradient backgrounds for feature icons
- Size: `h-12 w-12` rounded-xl
- Colors rotate through primary, accent, secondary

## Responsive Behavior

### Mobile (< 640px)
- Single column layout
- Stack CTA buttons vertically
- Full-width cards
- Reduced padding
- Smaller text sizes

### Tablet (640px - 1024px)
- 2-column grids
- Side-by-side CTAs
- Medium padding
- Medium text sizes

### Desktop (> 1024px)
- 3-column grids
- Horizontal layouts
- Floating elements visible
- Large padding
- Large text sizes

## Interaction States

### Hover
- Cards: Scale up (105%) + shadow increase
- Buttons: Scale up + shadow + color change
- Links: Color change to primary
- Icons: Translate or rotate

### Active/Click
- Scale down (95%) for tactile feedback
- Quick transition (100-200ms)

### Focus
- Ring around interactive elements
- Primary color ring at 20% opacity

## Theme Integration

All components automatically adapt to 12 themes:
1. Emerald (light green)
2. Emerald Night (dark green)
3. Celeste (blue)
4. HiCon (high contrast B&W)
5. Arctic (teal/cyan)
6. MonoChrome (grayscale)
7. Sunset (orange/yellow)
8. Sepia (vintage brown)
9. Coral Fushia (pink)
10. Midnight (purple/indigo)
11. Rosey (crimson/rose)
12. Storm (dark slate/blue)

Theme switcher in navbar allows instant theme changes with smooth transitions.

## Animation Timing

When Framer Motion is added:
- Fade-in: 0.3-0.5s
- Slide: 0.3-0.5s with ease-out
- Scale: 0.2-0.3s
- Stagger delay: 0.1-0.15s between items
- Hover: 0.2s transition
- Scroll trigger: When 20% of element is visible

## Accessibility Features

- Semantic HTML structure
- ARIA labels on icon buttons
- Keyboard navigation (Tab order)
- Focus indicators
- High contrast ratios
- Screen reader friendly
- Alt text on images (when added)
