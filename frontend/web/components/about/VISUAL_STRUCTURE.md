## Spacing Measurements

```
Section Padding:
├── Mobile:  80px vertical (py-20)
├── Tablet:  80px vertical
└── Desktop: 112px vertical (py-28)

Component Gaps:
├── Small:   24px (gap-6)
├── Medium:  32px (gap-8)
└── Large:   48px (gap-12)

Text Spacing:
├── Title → Subtitle:    24px (mb-6)
├── Subtitle → Content:  32px (mb-8)
└── Section → Section:   64px (py-16)
```

```
Extra Large:  24px (rounded-3xl) - Hero cards
Large:        16px (rounded-2xl) - Standard cards

Small:         8px (rounded-lg)  - Badges

```

## Animation Sequence (Future)

```
1. Hero Section          → Fade in (0ms)
2. Stats (Card 1)        → Scale in (100ms)
3. Stats (Card 2)        → Scale in (200ms)
4. Stats (Card 3)        → Scale in (300ms)
5. Stats (Card 4)        → Scale in (400ms)
6. Problem Section       → Slide right (scroll trigger)
7. Solution Section      → Slide left (scroll trigger)
8. Mission Items         → Stagger up (scroll trigger)
9. Values Cards          → Scale in (scroll trigger)
10. Timeline Items       → Slide left (scroll trigger)
11. Vision Points        → Slide up (scroll trigger)
12. CTA Section          → Scale in (scroll trigger)
```

## Decorative Elements

```
Background Blurs:
  Size: 256-384px (w-64 to w-96)
  Opacity: 5-10%
  Blur: 3xl (48px)
  Placement: Corners, behind sections

Gradients:
  Background: from-primary/5 via-transparent to-accent/5
  Text: from-primary via-accent to-secondary
  Borders: Solid gradient wrapper

Shadows:
  Default: none
  Hover: lg (0 10px 15px -3px)
  Colored: shadow-primary/10
```

## Accessibility Features

```
Heading Structure:
<h1> Hero Title
  <h2> Section Titles
    <h3> Card Titles

Focus Indicators:
  Visible ring on all interactive elements
  Color: Primary with opacity

Screen Reader:
  Semantic HTML (<section>, <nav>, etc.)
  ARIA labels for icons
  Descriptive link text
```

## Performance Optimizations

```
✓ Static generation (SSG)
✓ No client-side fetching
✓ Pure CSS (no CSS-in-JS)
✓ Minimal JavaScript
✓ Tree-shakeable components
✓ Optimized Tailwind output
✓ No external dependencies
```

**Note**: This is a text representation of the visual structure. The actual implementation uses modern CSS, responsive design, and theme-aware colors that adapt automatically to all 12 ConQ themes.
